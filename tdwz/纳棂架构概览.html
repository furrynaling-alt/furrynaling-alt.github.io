架构创新与核心亮点

项目中独具特色的技术方案

Token 全站访问网关

统一 token-check.js 模块拦截所有页面入口，JWT 签名验证 + URL Token 直传双模式。7 天有效期，支持无感刷新，过期自动跳转门户获取新 Token。

AES-256-GCM 加密聊天

所有 AI 聊天消息在云端以 AES-256-GCM 加密存储，即使数据库被拖库也无法解密。密钥由服务端环境变量管理，与代码完全分离。

双引擎内容审核

智谱 AI 模型（结构审核）+ 本地拼音/中文词汇库（实时拦截）双重保障。5 次违规永久封禁，评论与聊天全覆盖，无需人工干预。

五语言国际化零依赖

简中 / 繁中 / 藏语 / English / 日本語 五语言实时切换。纯 JS 字典实现，无 i18n 库依赖，localStorage 持久化语言偏好。

iOS 液态玻璃设计

backdrop-filter: blur + 多层内阴影 + 扫光动画，精确复刻 iOS 灵动岛视觉效果。明暗双主题自动跟随系统，CSS 变量驱动全局配色。

邮箱验证码登录

nodemailer + SMTP 发送 6 位验证码，60 秒冷却 + 单日 3 次限制。域名白名单仅允许 QQ/Gmail/Outlook/iCloud/163 邮箱。未注册自动创建账号。

零外部框架纯原生

全站仅 2 个外部 CDN 依赖（marked.js 渲染 Markdown、qrcodejs 生成二维码），其余全部使用浏览器原生 API。首屏加载 < 200KB。

Markdown 文档系统

云端 .md 文件 + 本地兜底数据，marked.js 实时渲染。支持 URL 参数路由、IntersectionObserver 章节定位、敏感信息脱敏、5 语言双语排版。
